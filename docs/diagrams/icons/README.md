# 構成図に使ったアイコンの出典

`01-architecture.drawio` と `01-architecture.svg` で使っている、配布元のSVG素材です。
図に埋め込んでいるため、ファイルを開く際に外部サイトから画像を取得する必要はありません。
SVG素材の内容は変更せず、図側で表示サイズだけを指定しています。

| 素材 | 公式の配布元 | バージョン・利用条件 |
| --- | --- | --- |
| aws-cloud, aws-user, aws-cloudformation, aws-eks, aws-iam, aws-s3 | [AWSの構成図用アイコン](https://aws.amazon.com/architecture/icons/) | Icon package 07312026（2026-07-31）。AWSは構成図や出版物での利用を認めています。配布元のAWSの利用条件が適用されます。 |
| kubernetes-deploy, kubernetes-svc, kubernetes-sa, kubernetes-pod | [Kubernetesコミュニティのアイコン集](https://github.com/kubernetes/community/tree/3bc2da62f72a7a05b8838014be60566668edc3e3/icons) | Apache-2.0またはCC-BY-4.0から選択できます。このリポジトリではApache-2.0を選択しています。[LICENSE-kubernetes.txt](LICENSE-kubernetes.txt) を参照してください。 |
| crossplane | [CNCFの素材集](https://github.com/cncf/artwork/blob/002662490acb2303c7301acc0256c00790e03e9f/projects/crossplane/icon/color/crossplane-icon-color.svg) | Linux Foundationの商標利用ガイドラインを参照する [LICENSE-cncf-artwork.md](LICENSE-cncf-artwork.md) を確認してください。 |

取得日：2026-10-06。各ファイルのチェックサムと取得元のURLは [sources.json](sources.json) に記録しています。
KRO、StorageApp、CrossplaneのManaged Resourceは文字で表し、独自のアイコンは作っていません。

この図は検証したラボの構成を説明するものです。AWS、CNCF、各プロジェクトの管理者による推奨を示すものではありません。
